# v2 data bundle (not committed)

The 12-country, 0.05° bundle is **distributed separately** because it is about 780 MB
uncompressed. It is generated by the analyst pipeline or copied from the team's release:

```bash
# from ninacal-pipeline-v2.2
make all WORKERS=4
cp -r web/data/v2/. /path/to/ninacal/data/v2/
```

The backend rebuilds its SQLite database from this directory:

```bash
python3 backend/scripts/build_db.py
```

The web app can run in static mode from this directory, or in API mode with
`NEXT_PUBLIC_API_BASE` pointing at the backend. See `../README.md`, `docs/data-v2/` and
`docs/NASA-COMPLIANCE.md`.

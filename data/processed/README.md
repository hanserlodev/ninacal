# `data/processed/`

Generated by the pipeline, committed by hand. One file per year:

```text
data/processed/
├── 2000.json
├── 2001.json
├── ...
├── 2026.json
└── calibration.json
```

## Rules

- Every file must validate against [`../schemas/`](../schemas/). CI checks parseability; the
  pipeline checks the schema.
- **`null` means missing, `0` means measured-zero.** Never fill with `0`.
- Sort rows by `cell`, then `y`, then `m` before committing: stable diffs, reviewable PRs.
- Do not commit partial years without saying so in the PR title and in
  [`../../docs/limitations.md`](../../docs/limitations.md).
- Files are public: no personal data, no coordinates of private property, no secrets.

## Regenerating

See [`../../pipelines/README.md`](../../pipelines/README.md). Never edit processed files by
hand; fix the pipeline and re-run it.

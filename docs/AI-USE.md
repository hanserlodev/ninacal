# AI use disclosure

The team used an AI coding assistant for:

- code generation, refactoring, debugging and test design;
- documentation and submission text;
- data-analysis scripts and review of validation results.

No AI-generated images, audio or video were used. The 30-second demo video was recorded,
narrated and edited by the team; the page that embeds it is hand-authored HTML/CSS. No NASA
logos, flags or mission identifiers are used anywhere in the project.

Every assisted change was reviewed, type-checked, built, and exercised against the live API and
the 153-country dataset. The scientific choices, data sources and limitations remain the team's
responsibility.
